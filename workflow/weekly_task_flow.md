# 週次制作フロー

## 目的

ショート動画週5本、長尺動画週1本を継続的に作り、チャンネル成長と収益導線につなげる。

## 毎週の流れ

### 1. チャンネル確認

対象チャンネル：
https://www.youtube.com/@%E3%81%97%E3%81%94%E3%81%A8%E6%94%B9%E5%96%84%E3%83%A9%E3%83%9C/shorts

確認する項目：

- 直近投稿テーマ
- 視聴回数
- タイトルの傾向
- 業界別テーマの反応
- 伸びた動画と伸びなかった動画の差
- 視聴者維持率
- 視聴を継続 / スワイプして消去
- YouTube検索流入の有無
- 投稿時間ごとの反応
- ナレーション設定ごとの反応

### 2. トレンド確認

毎回、Webで次を確認する。

- 今のAI活用トレンド
- 業務改善・Excel・小規模事業者向けテーマ
- 建設、介護、飲食、美容室、整体院、士業、不動産、運送、学習塾などの業界課題
- X、ニュース、YouTube上で話題になっている業務効率化ネタ

### 3. 過去テーマ確認

`topic_log/used_topics.md` を確認し、過去テーマと重複しないようにする。

重複扱いにする例：

- 同じ業界 + 同じ作業
- 似たタイトル構造で内容も近い
- 既存動画の焼き直しに見えるもの

### 4. 過去実績確認

可能ならYouTube Studioの数字、またはチャンネル上で見える視聴回数を確認する。

確認するもの：

- 視聴回数が高い動画
- 視聴回数が低い動画
- 投稿時間
- タイトル形式
- 業界ジャンル
- ナレーションの長さ
- 冒頭フックの種類

この結果をもとに、投稿時間・タイトル・ナレーション・画像構成を少しずつ変える。

### 5. 今週の企画作成

作るもの：

- ショート動画：5本
- 長尺動画：1本

優先順位：

1. 過去に反応があった業界の続編
2. 小規模事業者向けの具体作業
3. Excelで見える化できる作業
4. AIで下書き・整理できる作業
5. 長尺化しやすいテーマ
6. 今週のトレンドに寄せられるテーマ

### 6. 投稿時間の決定

標準：

- ショート：21:00
- 長尺：20:00

ただし、検証のため以下も試す。

- 朝：7:30
- 昼：12:00
- 夕方：18:30
- 夜：21:00
- 遅め：22:30

毎回固定せず、過去結果を見て少しずつずらす。

### 7. 素材作成

ショート動画：

- 9:16画像
- 画像ZIP
- VOICEVOX用SRT
- description.txt
- fixed_comment.txt
- title.txt
- project.json

長尺動画：

- 16:9画像
- 25〜35枚前後
- 画像ZIP
- VOICEVOX用SRT
- description.txt
- fixed_comment.txt
- title.txt
- chapters.txt
- project.json

### 8. GitHub保存

保存先例：

```text
assets/shorts/YYYY-MM-weekN/01_動画名/
assets/shorts/YYYY-MM-weekN/02_動画名/
assets/longform/YYYY-MM-weekN/01_動画名/
```

### 9. 投稿後レビュー

投稿後に `analytics/review_template.md` に結果を記録する。

見る数字：

- 視聴回数
- 平均視聴時間
- 視聴者維持率
- 視聴を継続 / スワイプして消去
- いいね
- コメント
- 登録者増加
- 検索流入
- 投稿時間
- ナレーション設定

## 改善ループ

1. 作る
2. 投稿する
3. 数字を見る
4. 伸びた型を残す
5. 弱い型を修正する
6. 投稿時間を試す
7. タイトルを試す
8. ナレーションを試す
9. 次週の企画に反映する
