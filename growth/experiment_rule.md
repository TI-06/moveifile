# 成長・検証ルール

## 目的

しごと改善ラボの動画を、作りっぱなしにせず、視聴回数・投稿時間・タイトル・ナレーション・画像構成を毎週改善する。

## 毎回見るもの

- 過去動画の視聴回数
- 公開日時
- 投稿から24時間後の伸び
- 投稿から48時間後の伸び
- 可能なら平均視聴時間
- 可能なら視聴者維持率
- 可能なら視聴を継続 / スワイプして消去
- 業界テーマごとの反応
- タイトル表現ごとの反応

## 投稿時間の検証

標準は以下。

- ショート：21:00
- 長尺：20:00

ただし、結果を見ながら以下を試す。

- ショート：7:30
- ショート：12:00
- ショート：18:30
- ショート：21:00
- ショート：22:30
- 長尺：19:00
- 長尺：20:00
- 長尺：21:00

同じ時間に固定しすぎず、週ごとに少しずつずらして反応を見る。

## タイトル検証

優先するタイトル型：

- 業界名 + 具体作業 + まだ〇〇してる？
- 〇〇、毎回ゼロから作ってる？
- 〇〇、Excelでここまでできます
- 〇〇、AIで下書きできます
- 〇〇、まずはこれだけでOK

避けるタイトル：

- 抽象的すぎるもの
- AIやChatGPTを前に出しすぎるもの
- 誰向けか分からないもの
- 過去動画と似すぎるもの

## ナレーション検証

検証するもの：

- 速度：1.00 / 1.05 / 1.10
- 声：白上虎太郎 / 玄野武宏 / 青山龍星
- 文体：やさしめ / 実務寄り / 少し強めの問題提起
- 冒頭：疑問形 / 断定形 / 共感形

VOICEVOX用SRTは、読み間違えやすい漢字をひらがな化する。

## 画像検証

検証するもの：

- 1枚目のフック画像の強さ
- 文字量
- キャラの有無
- 背景の明るさ
- 図解量
- 余白
- 悩み直撃の見出し

ショートは1枚目で止める。
長尺はサムネと冒頭30秒で離脱を防ぐ。

## 改善判断

### 伸びたと判断する基準

- 直近平均より視聴回数が高い
- 投稿24時間で反応が良い
- 視聴維持率が高い
- コメントや保存がある
- 登録者増につながる

### 改善する基準

- 直近平均より明らかに弱い
- 冒頭で離脱している
- タイトルが抽象的
- 誰向けか弱い
- 似たテーマが続いている

## 次回制作への反映

各週の終わりに、次を決める。

- 残すタイトル型
- 避けるタイトル型
- 伸びた業界
- 弱かった業界
- 次に試す投稿時間
- 次に試すナレーション設定
- 長尺化する候補
