# ショート動画作成Rule

## 基本方針

- 顔出しなし。
- 画像 + 読み上げ音声で作る。
- 追加テロップは基本なし。
- 画像内テキストで要点を見せる。
- 読み上げ音声で補足する。
- 画像はAIっぽさを抑え、自然で実務的なデザインにする。
- 世界観は「しごと改善ラボ」で統一する。
- キャラは、やさしく穏やかな男性案内役とミニキャラ版を優先する。

## 絶対NG

- 1枚に複数カットをまとめた設計表画像。
- 台本・秒数・SRTまで入ったストーリーボード画像。
- スライド一覧のような画像。
- 画像1枚に情報を詰め込みすぎること。

## サイズ

- 縦型。
- 9:16。
- 1080×1920。

## 標準構成

1. サムネ風フック画像
2. 悩み提示
3. 解決策1
4. 解決策2
5. 解決策3
6. 注意・コツ
7. まとめ
8. 固定エンドカード

## 画像ルール

- 1カット1画像。
- 画像はすべて別々のファイル。
- まとめて生成してよいが、出力は別画像にする。
- 1枚の設計表画像は禁止。
- 画像内には、大きな見出し・要点・図解を入れる。
- 文字を詰め込みすぎない。

## 台本ルール

- 画像ごとに読み上げ音声用の文を作る。
- 1カット1〜2文を基本にする。
- 読み上げは短めにする。
- 画像内の文字を全部読ませない。

## VOICEVOX用SRTルール

- SRTはVOICEVOXで正しく読ませるための読み上げ用データとして作る。
- 表示用ではなく、読み上げ精度を優先する。
- 読み間違えやすい漢字は、ひらがな化する。
- 業界用語も必要に応じてかな表記にする。
- 文を短くする。
- 句読点を入れて、読みやすくする。

## 自動動画生成ツール用の必須出力物

各ショート動画フォルダには、必ず以下を入れる。

```text
images.zip
voicevox.srt
description.txt
fixed_comment.txt
title.txt
project.json
```

## project.jsonルール

ショート動画では以下を基本形にする。

```json
{
  "video_type": "short",
  "video_mode": "short_vertical",
  "title": "動画タイトル",
  "recommended_publish_at": "YYYY-MM-DD 21:00",
  "images_zip": "images.zip",
  "srt": "voicevox.srt",
  "description": "description.txt",
  "fixed_comment": "fixed_comment.txt",
  "status": "ready"
}
```

## GitHub保存先

```text
assets/shorts/YYYY-MM-weekN/01_動画名/
```

## テーマ選定ルール

- 毎回、今の流行・伸びやすそうな業界・過去テーマとの重複を確認する。
- 過去動画と似すぎるテーマは避ける。
- タイトルでは、AIやChatGPTを前に出しすぎず、具体的な悩みを優先する。
- 自動生成ツールで使えるように、公開推奨日時も必ず決める。
